# 旋转跳跃我闭着眼

一个极简 macOS 菜单栏工具：按下你设置的快捷键，光标跳到下一块屏幕中心，并显示一次定位放大圈。默认快捷键是鼠标侧键，也可以改成双击 Option 或键盘组合键。

## 构建

```bash
./scripts/build_app.sh
```

构建完成后会输出 `.app` 路径，例如：

```text
/Users/juifen/Downloads/旋转跳跃我闭着眼/旋转跳跃我闭着眼.app
```

之后可以直接在 Finder 里双击 `旋转跳跃我闭着眼.app` 使用，不需要从终端启动。首次运行仍需要在系统设置里授予输入监控权限；授权后回到应用窗口点击“重新检测”。

更推荐安装到 `/Applications` 后再授权，避免 macOS 因为开发目录里的 App 被替换而重置权限：

```bash
./scripts/install_app.sh
```

## 默认行为

- 默认使用鼠标侧键触发，首次按下扩展鼠标按钮时会自动记住按钮编号。
- 菜单栏里可以打开“设置快捷键…”，改成双击 Option、键盘组合键或其他鼠标侧键。
- 使用鼠标按钮触发时，可以切换是否拦截侧键原事件。
- 多屏时按 `NSScreen.screens` 顺序循环到下一屏；单屏时只显示定位效果。
