# 光标回航 PointerPilot

![光标回航 PointerPilot 海报](Resources/poster.svg)

**一键让光标归位。**

PointerPilot 是一个极简 macOS 菜单栏工具，专为多屏工作设计。按一下鼠标侧键，光标立即回航到下一块屏幕中央，并显示一次轻量定位动效。它不接管你的工作流，只在你需要找回光标的那一刻出现。

## 为什么需要它

多屏工作时，光标最容易消失在屏幕边角、全屏窗口、竖屏显示器、Sidecar 或投屏画面里。你知道它还在某个地方，但下一秒就开始晃鼠标、扫屏幕、打断正在写代码、剪视频、做演示或开会的节奏。

**光标回航** 把这个动作压缩成一次点击：按下侧键，光标回到视线中心。

## 适合场景

- 外接显示器 + MacBook 屏幕的双屏办公。
- 三屏、竖屏、Sidecar 或投屏环境下频繁切换注意力。
- 全屏应用、演示、会议、剪辑、设计、写代码时，光标突然不在视线里。
- 不想安装大型鼠标增强工具，只需要一个安静、明确、好用的小工具。

## 亮点

- **一键回航**：默认使用鼠标侧键触发，手不用离开鼠标。
- **可换触发方式**：没有侧键时，可以改成双击 Option 或任意键盘组合键。
- **多屏循环定位**：按 `NSScreen.screens` 顺序把光标送到下一块屏幕中央。
- **轻量定位动效**：透明无边框 overlay，不抢焦点，不打断当前窗口。
- **菜单栏常驻**：只保留必要设置，不把简单问题做复杂。

## 构建

```bash
./scripts/build_app.sh
```

构建完成后会输出 `.app` 路径，例如：

```text
/Users/juifen/Downloads/PointerPilot/光标回航.app
```

之后可以直接在 Finder 里双击 `光标回航.app` 使用，不需要从终端启动。首次运行需要在系统设置里授予输入监控权限；授权后回到应用窗口点击“重新检测”。

更推荐安装到 `/Applications` 后再授权，避免 macOS 因为开发目录里的 App 被替换而重置权限：

```bash
./scripts/install_app.sh
```

## 默认行为

- 默认使用鼠标侧键触发，首次按下扩展鼠标按钮时会自动记住按钮编号。
- 菜单栏里可以打开“设置快捷键…”，改成双击 Option、键盘组合键或其他鼠标侧键。
- 使用鼠标按钮触发时，可以切换是否拦截侧键原事件。
- 多屏时按 `NSScreen.screens` 顺序循环到下一屏；单屏时只显示定位效果。
