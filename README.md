# 旋转跳跃我闭着眼

![旋转跳跃我闭着眼海报](Resources/poster.svg)

一个极简 macOS 菜单栏工具，把多屏工作里最烦人的一件小事变成一次点击：找回光标。

按一下鼠标侧键，光标立刻跳到下一块屏幕中央，并出现一次轻量定位动效。没有复杂面板，没有工作流负担，常驻菜单栏，日常几乎感觉不到它存在。

## 为什么需要它

多屏工作时，光标经常会消失在边角、全屏窗口、竖屏显示器或 Sidecar 里。你知道它一定还在某个屏幕上，但下一秒就要开始晃鼠标、扫屏幕、打断正在写代码、剪视频、做演示或开会的节奏。

`旋转跳跃我闭着眼` 做的就是把这个动作压缩到最短：按一下，光标回来。

## 适合场景

- 外接显示器 + MacBook 屏幕的双屏办公。
- 三屏、竖屏、Sidecar 或投屏环境下频繁切换注意力。
- 全屏应用、演示、会议、剪辑、设计、写代码时，光标突然不在视线里。
- 不想安装大型鼠标增强工具，只需要一个“把光标送到下一块屏幕中心”的小工具。

## 亮点

- 默认使用鼠标侧键触发，手不用离开鼠标。
- 没有侧键时，可以改成双击 Option 或任意键盘组合键。
- 多屏按 `NSScreen.screens` 顺序循环；单屏时只显示定位动效。
- 透明无边框定位动效，不抢焦点，不打断当前窗口。
- 菜单栏常驻，只保留必要设置。

## 构建

```bash
./scripts/build_app.sh
```

构建完成后会输出 `.app` 路径，例如：

```text
/Users/juifen/Downloads/旋转跳跃我闭着眼/旋转跳跃我闭着眼.app
```

之后可以直接在 Finder 里双击 `旋转跳跃我闭着眼.app` 使用，不需要从终端启动。首次运行仍需要在系统设置里授予输入监控权限；授权后回到应用窗口点击“重新检测”。

更推荐安装到 `/Applications` 后再授权，避免 macOS 因为开发目录里的 App 被替换而重置权限：

```bash
./scripts/install_app.sh
```

## 默认行为

- 默认使用鼠标侧键触发，首次按下扩展鼠标按钮时会自动记住按钮编号。
- 菜单栏里可以打开“设置快捷键…”，改成双击 Option、键盘组合键或其他鼠标侧键。
- 使用鼠标按钮触发时，可以切换是否拦截侧键原事件。
- 多屏时按 `NSScreen.screens` 顺序循环到下一屏；单屏时只显示定位效果。
